# to run the code run
g++ -std=c++11 main.cpp Player.cpp dungeon.cpp items.cpp -o dungeon_game
and then open the dungeon_game.exe file

# what does this do
This is a basic dungeon crawler game with multiple floors, items, enemies, bosses, and classes
You start the game by choosing the class you want to play which determines your playstyle.
You can unlcok some unlockable classes by completing a certain number of floors.
You have to navigate a floor using a map of a algorithm generated dungeon to find a boss room to advance to the next floor
